# 小心这个“隐形杀手”-气道异物

> 更新时间：2026-09-17 (UTC+8)

点击上方蓝字 关注我们

气道异物，被称作儿童意外的“隐形杀手”。一颗花生米、一小块苹果、甚至一颗软糖，都可能造成气道堵塞，尤其是1~3岁的小宝宝。其实这类意外完全可以预防，下面花3分钟，看完这篇实用的预防指南。

**1**

**这些食物，最容易被“吸”进去**

**01**

**坚果类（占80%！）**

花生、瓜子、核桃——3岁前尽量别整颗喂，磨成粉或酱才安全。

**02**

**黏人精食物**

年糕、汤圆、麻薯——粘性强，卡住很难弄出来。

**03**

**带核、带刺、带皮**

枣、桂圆、话梅、鱼、果冻、整颗葡萄——切成小丁再吃！

**04**

**不是食物的食物**

小玩具零件、弹珠、纽扣电池、硬币——收好！孩子啥都往嘴里塞。

**防呛口诀，背下来！**

✔ 哭不喂，笑不喂，跑跳打闹不喂食

✔ 3岁内坚果磨成粉，葡萄切四瓣

✔ 小物件收高，玩具零件不漏

✔ 嘴里有食不说话，坐直了吃别躺下

**2**

**呛到了，怎么办？记住这几招！**

**还能咳、能说话、能喘气**

让他自己咳！ 别拍背，别喂水，别抠喉咙。

→ 轻度梗阻不需要急救操作，密切观察即可。

**❌ 重度梗阻信号（需立即施救）：**

无法咳嗽/说话、呼吸困难、面色口唇发紫、双手抓喉。

**1岁以上及成人：**

2025新标准：背5 + 腹5 交替！

体位准备：

• 站患者身后，双脚前后弓步，前脚距患者一脚宽，稳定重心

• 患者身体前倾约90度，张口

第1步：背部拍击（5次）

• 用掌根在两肩胛骨连线中点，快速向前下方拍击5次

• 目的：利用震荡+重力松动异物

第2步：腹部冲击（5次）

——“剪刀、石头、布”

• 剪刀：肚脐上2横指（定位）

• 石头：一手握拳，拳眼对准该点

• 布：另一手包住拳头，向内向上45°角快速冲击

• 力度参考：1~8岁儿童约3~5公斤力，成人约5公斤力

交替循环：

背5→腹5→背5→腹5……直至异物排出或患者失去反应。

**1岁以下婴儿**

**严禁腹部冲击！**改用“背拍+胸压”交替

背拍法

脸朝下趴前臂，头低脚高，

用掌根在肩胛骨中间快速向前拍 5次

胸压法

翻过来仰卧，头仍低于身体，

掌跟在两乳头连线中点按 5次

交替做

直到异物排出或宝宝无反应

→ 无反应立刻CPR，同时打120

**如果人已经没反应、没呼吸**

**1**

马上打120

**2**

开始心肺复苏（CPR）

**3**

每次开放气道时看一眼嘴里，有异物就取出

**这些“急救操作”反而是坑！**

**误区**

❌ 呛到了马上喂水

→ 馒头、年糕遇水会胀，堵更死！

❌ 盲目用手抠喉咙

→ 可能把异物推更深！

❌ 咳几声就好了，没事

→ 异物可能掉进支气管，反复咳嗽、肺炎，要去医院查！

**急救后必做3件事（2025新强调）**

**1**

观察至少15分钟

呕吐时立即将头偏向一侧，防二次窒息；

**2**

及时就医检查

即使咳出来了，也要排除残留异物或内脏损伤；

**3**

向医生说明急救过程

帮助判断并发症风险。
