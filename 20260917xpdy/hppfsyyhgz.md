# 【防疫指南】关注孕产妇健康——妇产科专家陶敏芳教授给“新妈妈”送上温馨提示

> 更新时间：2026-09-17 (UTC+8)

****

**孕产妇是新冠肺炎的易感人群，作为特殊人群，孕产妇的健康备受关注，那么在特殊时期，孕产妇要注意哪些问题呢？孕产妇感染了新冠病毒应该怎么办？市六医院妇产科专家陶敏芳教授来支招，这份给孕产妇的“防疫指南”请收好。**

✦+

+

**孕妇感染新冠病毒，胎儿会不会受影响？**

**陶敏芳教授表示，对于绝大多数无指标异常的健康孕产妇而言，如果感染新冠病毒，无需过度紧张和焦虑。**目前已有的研究表明，病毒不会通过胎盘屏障进入宫内影响胎儿的生长发育，因此不会导致胎儿不良、畸形的发生；即便是在孕早期，有限的数据也表明不会导致流产的发生。但是如果母体出现高烧等严重症状会导致妊娠早期胎儿丢失、妊娠中晚期胎儿窒息、甚至发生死胎等。

**针对妈妈感染了新冠病毒是否会传播给宝宝，已有的临床研究数据不支持存在新冠病毒的母婴传播的风险。**通常所说的母婴传播，即垂直传播，指的是病原微生物通过胎盘或产道，以及哺乳等方式，由亲代传播给子代的一种途径。

✦+

+

**如感染新冠病毒，****需注意哪些问题？**

考虑到孕产妇是特殊人群，属于弱势人群，妊娠本身可能会有妊娠并发症的产生，同时合并有其他的疾病，如果感染了新冠病毒可能诱发或加重产科合并症和并发症，因此孕产妇应该比一般健康人群更应加以重视，做好防护，尽量避免去人群拥挤或不通风的场所。陶敏芳教授强调，孕妇感染新冠病毒后，如无症状或轻症可居家隔离观察。**一旦有发烧症状，就要引起重视，如果体温超过38度或有其它不适症状，就应前往医院就医。**

✦+

+

**感染新冠病毒后，产检是否能延后？**

如果孕妇以往产检没有异常的现象，胎儿发育正常，可以适当延后产检时间。特殊检查如大排畸检查或唐氏筛查请与产前检查医生联系以确定检查时间。**在用药方面，陶敏芳教授指出，感染新冠的孕产妇千万不要自己随意用药，需要在产科专家和药师的联合指导下进行合理用药，主要是考虑到孕产妇的特殊性，其用药临床有严格的规定。**随意用药、叠加用药等不规范的用药行为将会增加孕产妇的肝脏负担，严重的可造成急性肝损伤。感染新冠的孕妇在居家观察期间，需要房间里多走动，避免血栓的发生。

✦+

+

**特殊时期，孕产妇是否需要额外补充营养？**

都说“多吃多喝多睡”增强抵抗力，那么孕产妇是否需要额外补充营养呢？对此，陶敏芳教授表示，在目前日常运动相对减少的情况下，孕产妇更要注重均衡膳食营养。**对于没有基础疾病、也没有营养不良等情况的健康人群而言，并不需要增加额外的营养，也不建议盲目服用一些保健产品。**可以多喝水、多吃富含维生素的食物，进食优质蛋白质。也可以用维生素C泡腾片泡水喝（半片/2000ml水/日）等。

**总结**

**怀孕是一个艰辛而又幸福的过程，面对新冠病毒，孕妈们不必过分焦虑，只要我们做好防护，合理营养，保持心情愉悦，提高自身抵抗力，是能够有效减低感染风险的。如果出现新冠症状，在做好个人防护的情况下就诊，保持乐观的心态，积极配合治疗，相信很快就能恢复健康。**
