**突如其来的消息**

**再次让癌症走进视线**

最新《2018全球癌症统计数据》报告显示，全球新增的癌症患者达到了1810万人，因为癌症死亡的人数为960万人。我国有新发病例数380.4万例，死亡病例229.6万例。

一般情况下，一个癌细胞从正常细胞发展为癌症，需要20年至30年。我国 80%的癌症患者发现时已为中晚期，5年生存率不足10%。如果能早发现、早诊断、早治疗，治愈率高达90%以上。

**高发5大癌症筛查**

威胁中国人健康的5大癌症：肺癌、肝癌、胃癌、食管癌、结直肠癌，根据国内外筛查指南和专家共识，该如何进行筛查呢？

**肺癌**

早期肺癌常常无明显症状，多数因体检发现。当病情发展到中晚期时，常出现刺激性干咳，痰中带血、胸痛、发热、气促等表现。

高危人群

1. 长期受环境污染，长期吸烟者、吸二手烟（被动吸烟）者；

2. 慢性肺部疾病（肺结核、矽肺、尘肺等）；

3. 人体内在因素（如家族遗传、免疫机能降低以及内分泌功能失调等）。

推荐检查

胸片、低剂量螺旋CT、肺癌易感基因检测

**肝癌**

早期肝癌多无症状和体征，超过一半的肝癌患者发现时已处于中晚期。右上腹疼痛或不适多为肝癌的首发症状，可逐渐出现腹胀、食欲不振、腹部肿块、黄疸、消瘦等症状。

 高危人群

1. 有慢性乙肝、丙肝病史；

2. 家族中已有确诊肝癌患者；

3. 30岁以上男性及长期酗酒者；

4. 脂肪肝、肝硬化病人；

5. 长期食用腌制、烟熏、霉变等食品者。

推荐检查

肝脏彩超、血清甲胎蛋白（AFP）

**胃癌**

胃癌起病隐匿，70%以上无明显症状。可逐渐出现消化不良的症状，如上腹部饱胀不适或隐痛、反酸、嗳气、食欲减退等，多数患者以为是慢性胃炎或胃溃疡而忽视。

高危人群

1. 有胃癌、食管癌家族史者；

2. 有慢性胃炎、胃息肉、消化性溃疡病史；

3. 有不良饮食习惯者：如喜烫食、过酸、过辣等刺激性食物，喜食熏烤、煎炸、硬质食物；饮食无规律，暴饮暴食者；经常食用可能霉变食物等；

4. 大量饮酒，年龄40岁以上；

5. 精神压力大，长期抑郁、焦虑者。

推荐检查

胃镜检查、胃癌易感基因检测

**食管癌**

早期食管癌症状往往不明显，容易被忽略。随病情进展可出现胸骨后不适、吞咽时轻度哽噎感、异物感等，可间断或反复出现，甚至长达数年。

 高危人群

1. 有家族遗传史；

2. 爱吃烫食，爱喝烫茶；

3. 爱吃含致癌物亚硝酸盐的泡菜；

4. 常吃霉变、烟熏、麻辣食物。

推荐检查

胃镜检查

结直肠癌

结直肠癌早期症状不明显，或仅感食欲不振、粪便潜血等，随着癌肿发展，症状逐渐显现，表现为排便习惯改变、腹痛、便血、消瘦等。常误认为是“痔疮”。

 高危人群

1. 长期摄入高脂、高蛋白、高热量食物的人；

2. 40岁以上，长期摄入酒精、油炸食品等；

3. 有慢性溃疡性结肠炎、大肠腺瘤、家族性结肠腺瘤病、大肠息肉等慢性溃疡性结肠炎者；

4. 有大肠癌家族史者。

推荐检查

肠镜检查、肛门指诊检查、结直肠癌易感基因检测
